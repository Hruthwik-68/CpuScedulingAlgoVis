📘 What is CPU Scheduling?

CPU Scheduling decides which process (task) runs next on the processor. This simulator helps you visualize how different algorithms work:

  • CFS: Picks process with least execution time.
  • MLFQ: Gives higher priority to short tasks and lets tasks change levels.
  • RR: Gives each process a fixed time (like taking turns).
  • EDF: Picks process with the earliest deadline.
  • O(1): Schedules in constant time based on ready queue.

🔸 PID: Unique name for process (e.g., P1)
🔸 Arrival Time: When process comes to CPU
🔸 Burst Time: How long it needs CPU
🔸 Priority: (used in MLFQ) Lower number = higher priority
🔸 Deadline: (used in EDF) Smallest deadline goes first
